# 電気情報工学セミナーA テーマ12：AIに任せるか、人間が決めるか

インシデント対応AIエージェントにおける「人間の介在」を設計・評価する実習の教材です。

## 構成

```
docs/   各回の実習マニュアル（01_session1.md から順に）
code/   プログラム（必ずこのフォルダで実行する）
data/   模擬アラート（すべて架空）
```

## はじめに

`docs/01_session1.md` の「3. 環境構築」から始めてください。

## 注意

- APIキーは絶対にコミットしないこと（`.gitignore` で `.env` は除外済み）。
- `results/` と `code/logs/` は各自の手元にだけ残し、リポジトリには含めない。
